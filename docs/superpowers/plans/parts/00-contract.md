## Interface Contract (binding for all tasks)

All later tasks MUST use exactly these names and types. Rust structs/enums that cross IPC derive `serde::{Serialize, Deserialize}`, `specta::Type`, use `#[serde(rename_all = "camelCase")]` for structs and `#[serde(tag = "kind", rename_all = "camelCase")]` for data-carrying enums (unit-only enums: `#[serde(rename_all = "camelCase")]`).

### core: error.rs
```rust
pub enum NetworkKind { Timeout, Refused, Dns, Other }
pub enum CoreError {
    Network { kind: NetworkKind, message: String },
    HostKeyRejected { message: String },            // user declined / fail-closed
    Auth { rejected_methods: Vec<String>, message: String },
    Keyring { message: String },
    Store { message: String },
    Config { message: String },
    Io { message: String },
    Cancelled,
    Internal { message: String },
}
pub type Result<T> = std::result::Result<T, CoreError>;
```

### core: connect
```rust
pub enum Step { JumpHost, Tcp, HostKey, Auth, Channel, Shell }
pub enum ConnectEvent {
    Steps { steps: Vec<Step> },
    StepStarted { step: Step }, StepDone { step: Step }, StepFailed { step: Step, error: CoreError },
    Log { line: String },                                       // sanitized
    Prompt { prompt_id: u64, prompt: Prompt },
    Connected { session_id: SessionId },
    Failed { error: CoreError },
}
pub struct KbdPrompt { pub text: String, pub echo: bool }
pub enum Prompt {
    HostKeyUnknown { host: String, port: u16, info: HostKeyInfo },
    HostKeyChanged { host: String, port: u16, stored: HostKeyInfo, current: HostKeyInfo },
    KeyboardInteractive { name: String, instructions: String, prompts: Vec<KbdPrompt> },
    Password { user: String, host: String, retry: bool },
    Passphrase { key_path: String },
}
pub enum HostKeyDecision { Reject, AcceptOnce, Trust, Replace }
pub enum PromptAnswer {
    HostKey { decision: HostKeyDecision },
    Responses { values: Vec<String> },            // keyboard-interactive
    Secret { value: String, save: bool },         // password / passphrase

}
pub struct PromptBroker;  // new(emit: Arc<dyn Fn(ConnectEvent)+Send+Sync>); async ask(&self, Prompt) -> PromptAnswer (timeout 5 min -> Cancel); answer(&self, prompt_id: u64, PromptAnswer) -> bool
pub struct ConnectTarget { pub host: Host, pub profile: Option<LoginProfile> }
pub struct ConnectRequest { pub target: ConnectTarget, pub jump: Option<ConnectTarget>, pub cols: u16, pub rows: u16 }
pub struct ConnectDeps { pub known_hosts: KnownHosts, pub secrets: Arc<dyn SecretStore>, pub agent_sock: Option<PathBuf> }
pub async fn connect_ssh(req: ConnectRequest, deps: ConnectDeps, broker: Arc<PromptBroker>,

                         cancel: tokio_util::sync::CancellationToken) -> Result<SshSession>;
pub fn plan_steps(req: &ConnectRequest) -> Vec<Step>;   // JumpHost only if req.jump.is_some()
pub fn classify_io(err: &std::io::Error) -> NetworkKind;
```

`SessionEventDto` = `#[serde(tag="kind")] enum { Exit { code: Option<u32> }, Error { error: CoreError } }`.
AppState (src-tauri/src/state.rs): `{ paths: AppPaths, store: Arc<Store>, secrets: Arc<dyn SecretStore>, sessions: SessionManager, broker: Arc<PromptBroker>, connects: Mutex<HashMap<Uuid, CancellationToken>> }`.
Note: a single global `PromptBroker` routes answers; each `connect_ssh` call wraps its own events channel as the broker's emit for its prompts (implementation detail decided in the tauri task; `prompt_id` is globally unique).

### ui: ipc/api.ts
Exports one camelCase async function per command (`hostsList`, `hostSave`, `connectSsh`, …) delegating to generated `commands` in `bindings.ts`, unwrapping `{status:"ok"|"error"}` results into `Promise<T>` that rejects with `CoreError`. Helper `isCoreError(e): e is CoreError`.

### ui: stores (zustand)
- `useUiStore`: `{ view: "hosts"|"terminal"|"sftp", setView, modal: ModalState | null, openModal, closeModal, theme, setTheme }`
- `useHostsStore`: `{ hosts, groups, profiles, load(), saveHost(h), deleteHost(id), saveProfile(p), deleteProfile(id), filter: "all"|"ssh"|"sftp", setFilter, query, setQuery, selectedId, select(id) }`
- `useSessionsStore`: `{ tabs: Tab[], activeId, addTab(tab), closeTab(id), setActive(id), updateTab(id, patch) }` with `Tab = { id: string; title: string; kind: "ssh"|"local"; hostId?: Id; sessionId?: SessionId; status: "connecting"|"connected"|"closed"|"error" }`
- `useConnectStore`: `{ active: ConnectFlow | null, start(hostId, protocol), answer(promptId, answer), cancel(), retry() }` where `ConnectFlow = { connectId, hostId, protocol: "ssh"|"sftp", steps: Step[], current?: Step, done: Step[], failed?: {step: Step, error: CoreError}, log: string[], prompt?: {promptId: number, prompt: Prompt}, attempt: number, autoRetry: boolean }`
- `useSettingsStore`: `{ settings, load(), save(patch) }`
